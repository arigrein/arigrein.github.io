uno-r3.igs

ELEGOO UNO R3

Bypassing standard vendor SDKs to write bare-metal C code for the Uno, controlling the ATmega328P. Focused on register-level programming, writing custom startup code, bit masking, and handling hardware interrupts to understand the basics of bare-metal C programming.

57h93.igs

Toshiba 57H93

This is a 2004 rear projection CRT TV. I have spent countless hours trying to use this as a second monitor so I can output video from my laptop to its DVI port even though it was not meant for this. I found Linux to have more tools than Windows for fixing overscan, so I spent hours using the xrandr command to find the perfect setting. Unfortunately, the TV did not seem to like being used for this purpose and xrandr could not fully fix the overscan. The closest setting that I saved was unfortunately lost when I broke the OS on my MacBook. The best way to deal with the overscan that I have found is to just use the pop out player and size it to the correct dimensions while also hiding the taskbar and making the desktop background black if needed.
