The Workbench

A log of the hardware I am currently breaking, fixing, and experimenting with.

Lenovo Thinkpad P14s AMD Gen 6

Running Windows 11 and has an AMD Ryzen AI Pro 7. My primary laptop for college and app development and working with locally hosted AIs. I am going to work to dual boot Ubuntu with this since linux is better for working with my Raspberry Pi, and Ubuntu seems like the industry standard.

Dell XPS 8920 Desktop (Pop!_OS)

Running Pop OS Linux and has an Intel Core i5 and 1050ti. This is my main computer until it gets too hot in the summer then I switch to using a laptop in a cooler spot in my house. I put an RX 580 that was going to be recycled and was already heavily used in it. It worked for a few months before failing so I put back in the stock 1050ti.

2013 MacBook Air (Pop!_OS)

Running Pop OS Linux. I used it for app development before I got my current laptop. I accidentally messed up the OS and reinstalled it and am trying to fix the Wi-Fi on it not connecting to my router because modern Wi-Fi protocols are too complicated for its old Broadcom chip. I was able to fix this before the OS broke so I'll keep on trying to figure out what I did.

Toshiba 57H93 (2004 Rear-Projection CRT TV)

This is a 2004 rear projection CRT TV. I have spent countless hours trying to use this as a second monitor so I can output video from my laptop to its DVI port. I found Linux to have more tools than Windows for fixing overscan so I spent hours using the xrandr command to find the perfect setting. Unfortunately the TV did not seem to like being used for this purpose and xrandr could not fully fix the overscan. The closest setting that I saved was unfortunately lost with me breaking the OS on my MacBook. The best way to deal with the overscan (that I've found) is to just use the pop out player and size it to the correct size while also hiding the taskbar and making your desktop background black if needed.

2002 Compaq Presario 1700T

Running Windows XP and has an Intel Pentium III. I enjoy using this for seeing what old tech was like and for running games that modern Windows struggles to run (in my experience) like Age of Empires II. I want to try running Puppy Linux on it since that is known as a very small distro. I found out though (after trying many times) that booting through USB did not exist yet at the time so I will have to burn a CD when I do it.
